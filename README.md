# Light + Logic Digital — homepage

The redesigned homepage for Light + Logic Digital. A static site: HTML, CSS and JavaScript, animated with GSAP (ScrollTrigger, SplitText) and Lenis, loaded from a CDN.

## Run locally

```bash
python3 -m http.server 4173
```

Then open http://localhost:4173.

## Files

- `index.html` — page markup
- `styles.css` — design tokens, layout and components
- `main.js` — loading sequence, scroll scenes and the interactive demos
